# 竖店短剧小程序

> 长沙铜官窑古镇 · 短剧拍摄基地 — 整合短剧付费播放、线上教学、景区联动运营三大业务的微信小程序前端 HTML 实现

## 项目简介

需求方为长沙铜官窑片区的短剧拍摄基地，配套新华联铜官窑景区古建筑片场资源，同时拥有职业培训学校业务。本项目为微信小程序用户端前端原型，用纯 HTML + CSS + JS 实现，移动端 375px 居中布局，模拟微信小程序原生 UI 体验。

## 设计主题

- **主色**：铜官窑窑火红 `#C8252C`
- **辅助色**：古铜金 `#D4A24C`
- 古风 / 红金配色，呼应铜官窑古镇文化底蕴

## 公共文件

- `css/common.css` — 公共样式（CSS 变量、组件库、tabbar、卡片、按钮等）
- `js/common.js` — 公共脚本（导航栏、TabBar、Toast、返回等）

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript，无框架依赖
- 移动端 375px 宽度居中，模拟微信小程序原生 UI
- 所有数据为前端 mock 数据，可直接打开预览

## 快速预览

打开 `preview.html` 即可总览所有页面，点击缩略图进入对应页面体验。
或直接打开 `index.html` 从首页 TabBar 切换浏览整个小程序。

## 业务架构

```
统一用户体系 + 统一支付结算体系
├─ 短剧业务：内容上架 → 免费试看 → 付费解锁 → 平台收款 → 剧组分账
├─ 教学业务：课程上架 → 线上学习 → 学分统计 → 学历认定 / 技能付费
└─ 景区运营：资讯曝光 → 打卡任务 → 积分累计 → 门票兑换 / 权益核销
```
